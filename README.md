# Lista de Tarefas em JavaScript

Aplicação simples de lista de tarefas (To-Do List) desenvolvida com **HTML, CSS e JavaScript puro**, com foco em lógica, manipulação do DOM e persistência de dados.

## Funcionalidades

- Adicionar novas tarefas
- Impedir tarefas duplicadas
- Remover tarefas
- Feedback visual ao usuário
- Salvamento automático no navegador (localStorage)

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git e GitHub
